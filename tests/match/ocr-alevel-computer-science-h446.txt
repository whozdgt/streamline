# A Level Computer Science notes written for this test: revision cards, code snippets and past-paper answers. Each is
# under the point it is about.
=== 1.1.1 | CPU and FDE cycle
Components of the processor: ALU, control unit, registers - PC, ACC, MAR, MDR, CIR. Buses: data, address, control. Fetch-decode-execute cycle and the effect on registers. Factors affecting performance: clock speed, number of cores, cache. Pipelining. Von Neumann vs Harvard architecture.
=== 1.1.2 | CISC RISC GPU
CISC vs RISC processors: complex instructions vs simple ones executing in one clock cycle, RISC needs more RAM and compilers do more work. GPUs used for parallel processing, e.g. graphics, machine learning. Multicore and parallel systems.
=== 1.2.1 | OS revision
Operating systems: memory management (paging, segmentation, virtual memory), interrupts and the role of the ISR, scheduling algorithms: round robin, first come first served, multi-level feedback queues, shortest job first, shortest remaining time. Distributed, embedded, multi-tasking, real time OS. BIOS. Device drivers. Virtual machines.
=== 1.2.3 | waterfall agile etc
Software development methodologies: waterfall lifecycle, agile methodologies, extreme programming, spiral model, rapid application development. Merits and drawbacks. Writing and following algorithms.
=== 1.3.1 | lossy lossless hashing
Compression: lossy vs lossless, run length encoding, dictionary coding. Encryption: symmetric vs asymmetric (public and private keys). Hashing for passwords and hash tables.
=== 1.3.2 | SQL + normalisation
Relational databases, flat file, primary key, foreign key, secondary key, entity relationship modelling, normalisation to 3NF. SQL: SELECT ... FROM ... WHERE, JOIN, INSERT, DELETE. Referential integrity. Transaction processing, ACID (atomicity, consistency, isolation, durability), record locking and redundancy.
=== 1.3.3 | networks
TCP/IP stack - application, transport, network, link layers. DNS. Protocols and standards. LAN and WAN, packet and circuit switching. Network security and threats, firewalls, proxies, encryption. Client-server vs peer to peer.
=== 1.3.4 | HTML CSS JS + search engines
HTML, CSS and JavaScript. Search engine indexing, PageRank algorithm. Server and client side processing.
=== 1.4.1 | binary maths
Two's complement, sign and magnitude, binary addition and subtraction, hexadecimal, floating point binary with mantissa and exponent, normalisation, bitwise manipulation and masks: AND, OR, XOR, shifts. Character sets ASCII and Unicode.
=== 1.4.2 | data structures
Arrays (up to 3D), records, lists, tuples. Linked list, graphs (directed/undirected), stack (push, pop, peek), queue, tree, binary search tree, hash table. Traversing, adding and removing data from these.
=== 1.4.3 | boolean
Karnaugh maps, De Morgan's laws, distribution, association, commutation, double negation. D type flip flops, half and full adders.
=== 1.5.1 | laws
Data Protection Act 1998, Computer Misuse Act 1990, Copyright Design and Patents Act 1988, Regulation of Investigatory Powers Act 2000.
=== 2.1.1;2.1.2 | abstraction
Thinking abstractly: nature of abstraction, need for abstraction, differences between abstraction and reality. Thinking ahead: inputs and outputs, preconditions, caching, reusable program components.
=== 2.2.1 | recursion and OOP
Programming constructs: sequence, iteration, branching. Recursion vs iteration - factorial example. Global and local variables. Modularity, functions and procedures, parameter passing by value and by reference. IDEs. Object oriented techniques: classes, objects, methods, attributes, inheritance, encapsulation, polymorphism.
=== 2.3.1 | algorithms
Big O notation: constant, linear, polynomial, exponential, logarithmic complexity. Algorithms for stacks and queues. Tree traversal depth first (post-order) and breadth first. Bubble sort, insertion sort, merge sort, quick sort. Dijkstra's shortest path, A* algorithm. Binary search and linear search.
